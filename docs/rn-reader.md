# Spec: Expo 阅读器

## Objective

用 Expo（React Native）重做手机阅读器。Flutter 的 WebView 和桌面插件把阅读路径做成了难用的宿主；新客户端把阅读壳放在 `react-native-webview` 和原生视图上，阅读协议仍用现有 Reader Runtime 1.0.0 与 locator schema v1。

用户是把书放在自己手机里、要翻页读完的人。纯文本、RTF、DOCX、ODT、MOBI、AZW3、CHM、DJVU、EPUB、PDF、FB2、CBZ、CBT、CBR 和 CB7 已经能打开，刷新后书、进度和封面还在。WebDAV 和 S3 都可以拉书，也可以把书架上还没有的书推回去。阅读进度写进 `universal-reader-sync.json`，和另一台设备按内容哈希合并。当前文本、EPUB 章节和 PDF 当前页可以向用户自己填写的 OpenAI 兼容接口提问，问答记在这本书上。文本和 EPUB 可以问整本书，把这本书的命中交给模型，确认后才跳到命中处。模型也可以提议跳到这本书的另一处，用户确认后才翻页。用户可以把一条回答存成这本书的笔记。引文如果就在当前文本、EPUB 章节或 PDF 当前页里，会标在原文上。PDF 可以在这本书的页文本里查找，也可以把命中交给模型，确认后才打开那一页。

Flutter 工程 `app/` 保留，直到 Expo 能打开同一批 `test-books/` 样本。桌面（Windows / macOS / Linux）仍由现有 Flutter 与 Rust 服务负责，不在 Expo 目标里。

## Assumptions

1. 新工程在仓库根目录 `mobile/`。目录不能叫 `expo/`，否则和 `expo` 这个依赖同名。包管理用 npm。
2. 目标运行时是 iOS、Android，以及开发时的 Expo Web。
3. 纯文本行为对齐 `app/lib/core/text_document.dart`：UTF-8 / UTF-16 BOM、非法 UTF-8 走 GBK、超过 1 MiB 标截断、Markdown 按 ATX 标题分章、HTML 去掉 script/style。
4. 空文件是不可用，单独的 `0xFF` 是损坏。不拿另一本书或样章填上。
5. 界面文案走中英字符串表。书名和正文保持原样。
6. Rust HTTP 服务、CHM/DjVu C ABI 以后再接，这一刀不改它们。
7. EPUB 章内分页复用 `app/assets/reader/foliate/` 的 `paginator.js`。页码还没报上来之前，下一页不能跳章。一章的最后一页再往后，才进入下一章的第一页；一章的第一页再往前，打开上一章的最后一页。本地图片内联成 data URI；缺失的图保持缺失。
8. PDF 不走原生 PDFium。页画在 WebView / iframe 里的 pdf.js 画布上，关掉 PDF 内脚本。空文件是不可用；开头不是 `%PDF-` 的是损坏。pdf.js 打不开的文件在阅读页显示损坏，不换成别的书。页数没报上来之前不能翻页。最后一页再往后停住。手写批注这一刀不做。页面缩放见 36。正文查找只查这一本里能读出的页文本：空查询没有命中，同一页只算一条，最多 10 条。点命中才打开那一页。读不出文字时不编造命中。
9. 漫画打开 CBZ（ZIP）、CBT（tar）、CBR（RAR）和 CB7（7z）。图片按文件名不区分大小写排序，跳过文本、点文件和 `__MACOSX`。没有图片的包是损坏。叫 `.cbr` 或 `.cb7` 的 ZIP 或 tar 仍标成还不能打开，不改用 CBZ 的解法。空文件是不可用。像 RAR 或 7z 但解不开的是损坏。单页、双页、竖滑和从右到左见 37。解压走纯脚本，不另加原生模块。
10. 书架存在本机 SQLite。书的身份是文件字节的 SHA-256，和 Flutter 的 `contentHash` 同一算法。同一份字节再次打开仍是这一本，章和页不重置。空库保持空。格式不认识、位置不是非负整数、字节不是本机二进制的行丢掉，不拿另一本书填上。库版本比这一版新时拒绝打开，并且不覆盖原库。旧库只有书和进度时，补上一列可空的封面，不擦掉已有的书。每本书的正文字节单独读取；同一条结果里的多个二进制不能共用一块会被覆写的内存。
11. 封面只来自这本书自己的字节。EPUB 先用 OPF 里 `meta name="cover"` 或 `properties` 含 `cover-image` 的那张图，没有再按文件路径排序取第一张图片。CBZ、CBT、CBR 和 CB7 的封面就是阅读顺序的第一页。DJVU 的封面是按页面自己的分辨率画出的第一页。FB2 的封面是 `title-info` 里 `coverpage` 指向的那张 `binary`，远程地址不用，别的图也不拿来填。解不开、没有图片、TXT、Markdown、HTML、RTF、DOCX、ODT、MOBI、AZW3、CHM、PDF 都没有封面。封面失败不挡住打开，也不拿另一张图或色块填上。`__MACOSX` 不区分大小写地跳过。
12. 正文查找只查当前打开的这一本，不建另一份索引，也不改 Rust 的检索接口。TXT、Markdown、HTML 按章节做子串匹配，和已有的 EPUB 查找一样：空查询没有命中，最多 10 条。命中打开这一本的那一章。另一本书里的句子不会出现。漫画这一刀不编造正文命中。PDF 按能读出的页文本做同样的子串查找。
13. WebDAV 只处理当前目录这一层。地址必须是带主机的 http 或 https，用户名和密码只放在这次请求的 Basic 认证里，不写进书架，也不写进错误信息。PROPFIND Depth 1。别的主机、目录外面、子目录、`universal-reader-sync.json`、超过 64 MiB、以及这一版打不开的格式都不下载。某一本下不下来时，同一目录里其他能打开的书仍然导入。拉下来的书走原来的书架：同一份字节还是一本，不重置进度。空目录或全是打不开的文件时，书架保持原样。
14. 推到 WebDAV 只上传远端还没有的文件名。文件名是书架标题加上格式后缀，Markdown 用 `.md`。同名文件留在远端，不覆盖。空文件、超过 64 MiB、带 `..` 或斜杠的标题不上传。某一本推失败时，其他本仍然上传，书架上的进度不动。列目录失败时一本都不上传。
15. S3 导入走路径风格的 AWS Signature V4，直接请求用户填写的地址，不改 Rust 的 HTTP 协议。地址必须是带主机的 http 或 https。区域、存储桶、访问密钥和秘密密钥缺一不可，存储桶不能含斜杠。秘密密钥不写进书架，也不写进错误信息。ListObjectsV2 按前缀分页。前缀外面、`.` 或 `..` 路径段、`universal-reader-sync.json`、超过 64 MiB、以及这一版打不开的格式都不下载。某一本下不下来时，同一前缀里其他能打开的书仍然导入。列目录失败，或结果被截断却没有下一页记号时，一本都不导入，书架保持原样。
16. 推到 S3 只上传这个前缀里还没有的文件名。文件名是书架标题加上格式后缀，Markdown 用 `.md`。同名对象留在远端，不覆盖；前缀外的对象不算同名。空文件、超过 64 MiB、带 `..` 或斜杠的标题不上传。某一本推失败时，其他本仍然上传，书架上的进度不动。列目录失败时一本都不上传。
17. 阅读进度单独走 `universal-reader-sync.json`，不跟书籍文件混在一起。同一本书用内容哈希对齐。`last_opened_ms` 更新的那一份胜出；时间相同才取更大的进度。胜出的记录带有章和页时，书架停到那一章那一页，另一本书的位置不动。远端有、本机还没有的记录原样留在同步文件里。批注和删除墓碑按原协议合并，避免把另一台设备的笔记抹掉。版本不是 1、文件损坏或超过 16 MiB 时不上传替换。WebDAV 和 S3 都读写这一个文件。
18. 问这一页只针对当前打开的这一处正文。文本和 EPUB 用当前章节，PDF 用阅读页报上来的当前页文本。地址必须是用户填写的 http 或 https，并且不能带用户名或密码。模型名不能空。密钥只放在这次请求的 Bearer 里，不写进正文，也不写进书架或错误信息。请求体是 OpenAI 兼容的 chat completions，温度 0.2。摘录最多 4000 字。另一章、另一页的文字不会出现。摘录包在分隔线里，当作不可信数据。空摘录、页文本还没报上来、空回复、非 2xx 或网络失败都不编造答案，也不翻页、不写批注。打开面板本身不发请求。漫画这一刀还不能提问。
19. 问答记在这本书自己的书架记录里，最多 50 条，留下较新的。再次打开同一本书能看到原来的问题和回答。另一本书的问答不出现。空回答不写入。记录损坏时不覆盖成别的内容。删掉这本书时，它的问答一起删，另一本的还在。密钥不进问答记录。
20. 把一条回答存成笔记是用户点的，模型自己不写。笔记正文是这条回答，引文是当时的问题，定位是当时的章节。同一条回答再存一次不会变成第二条。空回答不写入。笔记最多 100 条，留下较新的。删笔记不影响问答，问答的增减也不改笔记。笔记行损坏时不改写成空的。删掉这本书时，它的笔记一起删，另一本的还在。引文出现在当前文本或 EPUB 章节里时，标在原文上。引文不在这一章、空白引文和书签不画。不把引文插进没有这句话的章节。另一本书不画。PDF 只在当前页的文字上画能对上的引文，对不上的不插入，也不画到别的页。
21. 模型可以在回答的最后一行单独写 `[[goto:N]]`，提议跳到这本书从 1 数起的第 N 处。只有这一行、并且 N 落在这本书里时，才出现确认按钮，这一行也不留在保存的回答里。用户点确认后才翻页。超出范围、写了不止一处、写在句子中间、只有这一行、或者用户不点，阅读位置都不动。另一本书不会被翻。漫画仍不能提问。
22. 问这本书只检索当前打开的 TXT、Markdown、HTML 或 EPUB。问题为空、没有命中、或命中落在这本书外面时不发请求，也不拿当前章节或其他书填上。最多把 5 条命中连同位置送给模型。每条命中都可以确认后跳到那一处。不点确认时位置不动。PDF 问整本时发送这一本的页文本命中，确认后才打开那一页。漫画仍不能提问。
23. FB2 按 `section` 分章，章序就是书里的顺序。只含下级 `section` 的节不是一章。书名来自 `book-title`，没有就用文件名。空文件是不可用。不是 `FictionBook`、解不开、或没有章节是损坏。`title-info` 里的 `annotation` 是第一章。第一节前面的 epigraph、cite、subtitle 留在第一章。名为 notes 或 comments、且没有 section 的 body，要等正文已经有章节才成为一章。另一本书的句子不会出现。
24. RTF 以 `{\rtf` 开头，前面的 BOM 和空白不算正文。空文件是不可用。不像 RTF、花括号没有合上、十六进制转义不完整、或没有章节是损坏。`\info` 里的 `\title` 是书名，没有就用文件名；作者用 `\author`，没有再用 `\operator`。`\s1` 到 `\s2` 以及对应的大纲级别另起一章，章名不重复写进正文。`\pard` 才结束这一级标题，所以紧跟着的下一段如果仍是 1 或 2 级，就是下一章。页眉、字体表、图片和 `\*` 组不进入正文。控制词后面的那一个空格是分隔符，不进入正文。`\u` 读成对应字符。`\ansicpg936` 和 `54936` 按 GBK 解码，`65001` 按 UTF-8，其余按 Latin-1。表格单元格用制表符隔开。正文超过 200 万字时截断，后面的章节不再显示。查找只查这一本，空查询没有命中，最多 10 条。另一本书的句子不会出现。RTF 没有封面。
25. DOCX 是 ZIP。空文件是不可用。解不开、没有 `word/document.xml`、XML 损坏、没有 `body`，或正文段落是空的，都是损坏。路径不区分大小写，反斜杠按斜杠处理。书名来自 `docProps/core.xml` 的 `title`，没有就用文件名；作者来自 `creator`。`Title`、`Heading1`、`Heading2` 和 `标题1`、`标题2` 另起一章，1 级和 2 级大纲也一样。章名不重复写进正文。3 级及更深的大纲留在当前章。列表段落前面加 `- `。表格单元格用制表符隔开，行与行换行。超链接只留下可见文字，地址不写进正文。正文超过 200 万字时截断，后面的章节不再显示。查找只查这一本，空查询没有命中，最多 10 条。另一本书的句子不会出现。DOCX 没有封面。
26. ODT 是 ZIP，并且 `mimetype` 必须是 `application/vnd.oasis.opendocument.text`。空文件是不可用。解不开、类型不对、没有 `content.xml`、XML 损坏、没有 `office:text`，或正文是空的，都是损坏。路径不区分大小写。书名来自 `meta.xml` 的 `title`，没有就用文件名；作者先用 `creator`，没有再用 `initial-creator`。`text:h` 的 `outline-level` 为 1 或 2 时另起一章，没有这个属性时用样式名里的 `Heading` 或 `标题` 级别，都没有则当作 1 级。章名不重复写进正文。3 级及更深的标题留在当前章。`text:section` 里的段落仍按同样的规则分章。列表项前面加 `- `。表格单元格用制表符隔开。`text:s` 按个数展开成空格，最多 100 个。换行留下。脚注不进入正文。超链接只留下可见文字。正文超过 200 万字时截断，后面的章节不再显示。查找只查这一本，空查询没有命中，最多 10 条。另一本书的句子不会出现。ODT 没有封面。
27. MOBI 和 AZW3 先按 EPUB 打开。文件开头不是 ZIP 时，从第一个 `PK` 头再试一次。能打开时，章节就是这本 EPUB 自己的章节，书名也用它的书名。打不开时，留下连续 24 个可读字符以上、并且含有字母或汉字的片段，拼成一章。空文件是不可用。没有这样的片段是损坏。查找只查这一本，空查询没有命中，最多 10 条。另一本书的句子不会出现。MOBI 和 AZW3 没有封面。
28. CHM 以 `ITSF` 开头。空文件是不可用。不是这种文件、解不开、或没有 HTML 页面是损坏。页面按文件名排序，`index` 和 `default` 排在前面。样式表不是一章。书名来自 `#SYSTEM`，没有就用第一页的标题，再没有就用文件名。章名用页面的 `<title>`。正文去掉标签。查找只查这一本，空查询没有命中，最多 10 条。另一本书的句子不会出现。CHM 没有封面。这一步不改 Rust 的 HTTP 契约，也不接 CHM 原生模块。
29. DjVu 以 `AT&TFORM` 开头，随后是 `DJVU`、`DJVM` 或 `DJVI`。空文件是不可用。不像 DjVu、或解不开是损坏。每一页按这一页自己的分辨率画成 PNG。共享样本是 1024×1024，白像素 266850，黑像素 781726。没有文字层时不编造说明。书名用文件名。封面就是第一页。阅读按页翻，和漫画同一套翻页。`.djvu` 和 `.djv` 都按 DjVu 打开。这一步不改 Rust 的 HTTP 契约，也不接 DjVu 原生模块。
30. 阅读设置记在本机，不属于某一本书。正文字号是 14 到 28，默认 18。行距是 1.4 到 2.2，默认 1.7。字体是衬线、无衬线和等宽，默认衬线。纸张是跟随应用、浅色或深色。跟随应用时用系统深浅色；这一版应用本身没有另一套主题。超出范围或认不出的值回到该项的默认，不改写已经损坏的记录。字号、行距、字体和纸张只作用在章节正文和 EPUB 页面上。换设置不移动阅读位置，也不改另一本书。PDF 页面缩放见 36。漫画版式见 37。
31. 书签记在这本书上，位置是当前章节和页。同一处再添加一次仍是这一条。空位置和负数不写入。书签没有引文，所以不在正文上画标记。点书签才回到那一处。删掉一条书签时，这本书的笔记和问答还在，另一本书的书签也不动。
32. 从书库删除要先确认。取消时这本书还在。确认后去掉这一本的正文、笔记和问答。另一本书不动。阅读设置不属于某一本，所以还在。
33. 在当前文本章节里选中一句正文，才能存成这条笔记。空白选区、这一章里没有的句子、空位置和负数不写入。同一句再存一次仍是这一条。笔记正文留空，引文是选中的句子，所以只标在含有这句话的章节上。另一本书看不到。
34. EPUB 当前章节里的选区同样存成这条笔记。章节文档报上来的空白选区和其它消息不算一句。这句话不在当前章节正文里时不写入。同一句再存一次仍是这一条。两份笔记引文相同时也只标一次。标在这一章的正文上。另一本书看不到。
35. PDF 当前页的文字层里选中一句，才能存成这条笔记。空白选区、这一页没有的句子不写入。翻到别的页时，刚才那句不再挂着。同一句再存一次仍是这一条。标在这一页的文字上，不标到别的页。另一本书看不到。
36. PDF 页面缩放记在同一份阅读设置里，不属于某一本书。档位是 100%、125%、150%、200%、300%，默认 100%。超出 1 到 3 倍的值按四分之一档夹回，认不出的值回到 100%。旧记录没有这一项时按 100% 读出，不改写已经损坏的记录。放大的是当前这一页的画面，文字层和这一页的引文标记一起变大。不翻页，不改另一本书的位置，也不改字号和纸张。
37. 漫画版式记在同一份阅读设置里，不属于某一本书。默认单页、从左到右。双页把这一本按文件顺序两张一对，从左到右时较早的一张在左；从右到左时较早的一张在右。最后一张落单时只显示这一张。下一页跳过一整对，上一页回到上一对的第一张，到头就停住。竖滑按文件顺序把每一页排开，从右到左不改这个顺序。认不出的版式回到单页，认不出的方向回到从左到右。旧记录没有这两项时按单页、从左到右读出。换版式不改字号、纸张和页面缩放，也不改另一本书的位置。DJVU 仍按一页翻。
38. 笔记列表只列这本书里来源不是书签的笔记。引文去空白后优先显示，没有引文就显示笔记正文，两者都空才显示定位。点一条带 `place:章:页` 的笔记才回到那一处。`2 / 2` 这种显示用的定位点了也不翻页。书签不出现在这个列表里。删一条笔记时，这本书的问答和另一本书的笔记还在。空白列表保持空白。
39. 书名和作者可以改，记在这本书上。书名去掉空白后为空时留下原来的书名。作者去掉空白后为空就清空。超过 200 字只留下前 200 字。改名不改这一本的正文、章节、页码和封面，也不改另一本。同一份字节再次导入仍用改过的书名和作者，章节和页不重置。找不到的书不改成别的名字。旧书架没有作者这一列时，作者是空的，书还在。书架版本仍是 5。
40. 书架查找按书名、作者、格式标签和这本书的笔记匹配，不区分大小写。格式用界面上的标签，Markdown 是 MD，所以 `markdown` 对不上。书的内部编号对不上。空白查询留下整架，顺序不变，也不去读笔记。一本书的笔记命中只留下这一本，另一本的句子不出现。书名和笔记同时命中时这一本只出现一次，仍按书架原顺序。笔记读不出来时，书名还能对上的书仍然留下。没有命中时列表是空的，书架上的书还在。
41. 阅读页底部显示这本书的进度百分比，并可以点进度条跳到对应的章节或页。两页的书停在第 1 页是 0%，停在第 2 页是 50%。一章有两页、整本有两章时，第一章的第 2 页是 25%。点到 0.49 仍停在开头，点到 0.5 或最右落到最后一处，不会超出这本书。同一处再点一次不改选区。离开时写入同步的进度仍按原来的页位置计算。认不出的进度停在开头。
42. 书架可以按全部、正在阅读和收藏筛选，也可以放进收藏夹。正在阅读只留下进度大于 0 且小于 1 的书。收藏只留下点过收藏的这一本，另一本不出现。再点一次就取消。空白书号不写入。收藏夹名称去掉空白后为空时不创建。超过 40 字只留下前 40 字。最多 50 个收藏夹。同一本再加入一次仍是这一本。删掉收藏夹后，书还在全部里。找不到的收藏夹不显示整架。损坏的收藏记录读出来是空的，并且不改写那一行。比这一版新的记录也不改写。收藏不改书的正文、章节、页码和阅读设置。书架版本仍是 5。删掉的书会从收藏和收藏夹里去掉。
43. 书架可以按书架顺序、最近阅读、标题或阅读进度排列。默认是书架顺序，空白查找仍按这个顺序。标题按字符顺序，大写排在小写前面。阅读进度大的在前。最近阅读按打开时间，新的在前。进度或时间相同、认不出的进度或时间，都留下原来的先后。换排序不改书的正文、章节和页，也不改另一本。全部里如果有一本进度大于 0 且小于 1，就标出最近打开的那本可以继续阅读。进度是 0 或 1 的书不标。点它才打开那一本。
44. 书架可以按全部格式、可重排、固定版式或漫画筛选。PDF 和 DJVU 是固定版式。CBZ、CBT、CBR、CB7 是漫画。其余能打开的格式是可重排。认不出的筛选不显示整架。换筛选不改书的正文、章节和页，也不改另一本。回到全部格式后，原来的顺序还在。
45. 漫画和 DJVU 页面按左、中、右三等分响应点击。从左到右时，左侧上一页，右侧下一页。从右到左时左右对调。中间切换页眉页脚。已经在第一页或最后一页时，再点那一侧不翻页。双页一次跳过这一对。点这一本不会打开另一本。宽度认不出来时只切换页眉页脚。
46. 可重排正文按左、中、右三等分响应点击。左侧上一页，这一章没有更早的页时回到上一章的最后一页。右侧下一页，这一章的最后一页再点就进入下一章的第一页。中间不翻页。已经有一句待保存的选区时，中间也不切换页眉。页数还没出来时不跳章。已经在开头或结尾时再点那一侧不翻页。点这一本不会打开另一本。中间仍可滚动和选字。

## Code Style

解析函数是纯函数，阅读文档自己保存章节下标。损坏和缺失是不同结果。

```ts
export function openTextDocument(
  metadata: DocumentMetadata,
  bytes: Uint8Array | null,
): OpenedTextDocument {
  if (bytes == null || bytes.length === 0) {
    return { kind: "unavailable", metadata };
  }
  try {
    return {
      kind: "text",
      document: TextReaderDocument.parse(metadata, bytes),
    };
  } catch (error) {
    if (error instanceof FormatError) return { kind: "corrupt", metadata };
    throw error;
  }
}
```

## Testing Strategy

- 先写失败测试，再写解析器。
- 覆盖：空白行分章、Markdown 标题、HTML 去标签、UTF-8 中文不被当成 GBK、GBK「第一章」、UTF-8 BOM、超过 1 MiB 截断、空字节不可用、`0xFF` 损坏。
- 不在测试里访问公网 WebDAV、S3、DeepSeek 或真机。WebDAV 用假的 PROPFIND 响应。S3 用假的 ListObjects 响应，并核对一条固定时间的签名。
- 纯文本覆盖保持通过。EPUB 另测：最小书的目录和跳章、嵌套 nav / NCX 片段、缺失章节停在当前章、脚本被去掉、本地图片内联、缺失图片不替换、损坏 ZIP 与空文件区分。
- 翻页规则另测：未知页数不跳章、章末进入下一章、章首回到上一章末页、布局未完成的页码报告被丢掉。
- 界面用 Expo Web 打开一本多页 EPUB，确认同一章里能翻页，最后一页再翻才进入下一章。
- PDF 另测：空文件不可用、不是 PDF 的字节损坏、带前导空白的 `%PDF-` 仍可尝试打开、最后一页不再往后、页数未知时不翻页。查找另测：空查询没有命中，一句话只命中含有它的那一页，另一本的句子不会出现，最多 10 条。读不出文字时没有命中。
- 界面用 Expo Web 打开 `test-books/pdf/minimal.pdf`，能看到这一页并翻到下一页；损坏文件只提示损坏。
- 漫画另测：CBZ 按文件名排序、跳过非图片、没有图片算损坏、CBT 能打开。CBR 和 CB7 打开自己的图片页，页图地址能还原成这一页的字节。叫 `.cbr` 或 `.cb7` 的 ZIP 仍是还不能打开。空文件不可用，解不开的 RAR 或 7z 是损坏。
- 漫画版式另测：双页把前两张放在一起，最后一张单独留下。从右到左时较早的一张在右。下一页跳过一整对，到最后一页停住。竖滑仍是一页一个位置，顺序不因方向改变。认不出的版式和方向回到单页、从左到右。保存双页和从右到左后，字号和这本书的章节不动。
- 界面用 Expo Web 打开 `test-books/cbr/minimal.cbr` 和 `test-books/cb7/minimal.cb7`，图片元素用的是这一页自己的字节；下一页仍是这本漫画。这两份样本的页面只有 PNG 文件头，浏览器画不出位图。能解码的图片会画在这一页上。
- 书架另测：重新打开同一个库文件仍能读回原字节；同一份字节不会变成第二本，进度保留；空库是空的；不认识的格式行丢掉；删除一本时另一本还在；更新的库版本拒绝打开且不擦掉已有的书。
- 界面用 Expo Web 打开一本书，记下页码后刷新，书架上还是这一本，打开后仍停在那一页。
- 封面另测：EPUB 标明的封面优先于包里另一张图；没有标明时按路径取第一张图；容器缺失或损坏则没有封面。CBZ、CBT、CBR 和 CB7 封面是第一页。FB2 封面是 coverpage 指向的那张图，远程地址和另一张 binary 不用。只有 `__MACOSX` 时没有封面。TXT / PDF 没有封面。封面随书存进书架，再次打开同一份字节不换掉已有封面，也不重置进度。旧版书架补上封面列后，原来的书还在，封面保持空。
- FB2 另测：空文件不可用，不是 FictionBook 或没有章节是损坏。共享样本打开自己的章节，另一本的句子不出现。只分组的 section 不是一章。书前 epigraph 留在第一章。诗行留在这一章。annotation 在正文前，notes 在正文后。查找只命中这一本。
- 界面用 Expo Web 打开 `test-books/fb2/minimal.fb2`，能看到 `first chapter text here`；下一章是 `second chapter text here`，仍是这本书。
- RTF 另测：空文件不可用，不像 RTF 或花括号没合上是损坏。共享样本打开自己的两章，另一本的书名不出现。页眉和字体表不进入正文。GBK 代码页读出自己的字。没有 `\pard` 时下一段仍是新的一章。查找只命中这一本，最多 10 条。超过 200 万字的章节被截断。
- 界面用 Expo Web 打开 `test-books/rtf/minimal.rtf`，能看到 `Unicode: 中文`；下一章是 `Second chapter body.`，仍是这本书。
- DOCX 另测：空文件不可用，不是 ZIP 或没有 `word/document.xml` 是损坏。共享样本打开自己的三章，另一本的书名不出现。列表带 `- `，表格用制表符。超链接地址不进正文。`标题1` 另起一章，更深的大纲留在这一章。查找只命中这一本，最多 10 条。超过 200 万字的章节被截断。
- 界面用 Expo Web 打开 `test-books/docx/minimal.docx`，第一章是书名；下一章能看到 `Hello bold and italic text.`；再下一章是 `Second chapter body.`，仍是这本书。
- ODT 另测：空文件不可用，不是 ODT 类型或没有 `content.xml` 是损坏。共享样本打开自己的两章，另一本的书名不出现。列表带 `- `，表格用制表符。脚注不进正文。`Heading_20_3` 留在当前章。查找只命中这一本，最多 10 条。超过 200 万字的章节被截断。
- 界面用 Expo Web 打开 `test-books/odt/minimal.odt`，能看到 `Hello bold and italic and strong underline.`；下一章是 `Second chapter body.`，仍是这本书。
- MOBI / AZW3 另测：空文件不可用，没有够长可读片段是损坏。共享样本各自打开自己的那一句，另一本的句子不出现。文件中间的 EPUB 打开的是那本 EPUB 的章节。查找只命中这一本。
- 界面用 Expo Web 打开 `test-books/mobi/minimal.mobi`，能看到 `Universal Reader sample text for MOBI decoding.`。`test-books/azw3/minimal.azw3` 能看到 `Universal Reader sample text for AZW3 decoding.`。这两本没有封面。
- CHM 另测：空文件不可用，不是 `ITSF` 是损坏。共享样本打开自己的两页，另一页的句子不出现。样式表不是一章。查找只命中这一本。
- 界面用 Expo Web 打开 `test-books/chm/minimal.chm`，能看到 `The quick brown fox jumps over the lazy dog.`；下一章是 `Second page of the rustchm basic test.`，仍是这本书。这本书没有封面。
- DjVu 另测：空文件不可用，不是 `AT&TFORM` 加 `DJVU` 是损坏。共享样本打开自己的一页，宽高都是 1024，白像素 266850，黑像素 781726。封面是这一页的 PNG。`.djv` 也按 DjVu 打开。

- 版式筛选另测：全部格式留下原来的先后，而且不改原数组。可重排留下 TXT、EPUB、CHM，去掉 PDF 和漫画。固定版式只留 PDF 和 DJVU。漫画只留 CBZ、CBR、CB7、CBT。认不出的筛选是空的。HTML、MOBI 和未知格式算可重排。

## Boundaries

- Always
  - 缺文件、损坏文件如实显示。
  - 正文和书名不翻译。
  - 新行为进 `mobile/src/`，并带测试。
- Ask first
  - 删除 `app/` Flutter 工程。
  - 把 EPUB / PDF 解析下沉进 Rust，或改 locator schema。
  - 接入 CHM/DjVu 原生模块。
- Never
  - 用样章填补打不开的文件。
  - 在这一刀改 Rust 服务的 HTTP 契约。
  - 把桌面平台算进 Expo 的完成标准。

- 把一条回答存成笔记后，再次打开仍能看到它已保存。另一本书没有这条笔记。引文出现在当前文本、EPUB 章节或 PDF 当前页时被标出，没有这句话的地方保持原样。
- 模型提议跳到本书另一处时，阅读页先停在原地，并给出确认。点确认后才打开那一处。不确认时位置不变。
- 问整本书后，阅读页显示接口根据这本书的命中返回的回答。点确认后才打开命中的那一处。没有命中时不发请求，正文保持原样。

## Later

文本、EPUB 和 PDF 可以就当前章节或当前页提问。文本、EPUB 和 PDF 可以问整本书，命中经确认后才跳转。模型也可以提议跳到这本书的另一处，用户确认后才翻页。这本书的笔记引文会标在当前文本、EPUB 章节和 PDF 当前页上。Flutter 目录在这一版也能打开这些样本之前不删。
